# Spend Tracker downloads

Installers for **Spend Tracker** by Growing Tendies, a private monthly money check for your household. Everything stays on your computer.

- **Windows:** [SpendTracker-Setup.exe](https://github.com/growingtendies/spend-tracker/releases/latest/download/SpendTracker-Setup.exe)
- **Mac:** [SpendTracker.dmg](https://github.com/growingtendies/spend-tracker/releases/latest/download/SpendTracker.dmg)

This repository holds downloads only. It contains no source code.

These test versions aren't code-signed yet, so Windows and macOS will show a warning the first time you open them.
